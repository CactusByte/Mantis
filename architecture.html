Agent Execution Loop (runner.py)

sequenceDiagram participant C as Caller
(Telegram / Scheduler) participant R as AgentRunner participant S as SessionStore participant W as workspace/ participant CL as Claude API participant TR as ToolRunner C->>R: run(session_id, text) R->>W: read SOUL.md + HEARTBEAT.md + MEMORY.md R->>S: load session history R->>R: append user message loop Agentic Loop R->>CL: messages + tool schemas CL-->>R: response (text | tool_use) alt tool_use R->>TR: run(tool_name, params) TR-->>R: tool result R->>R: append tool result else end_turn R->>S: save session R->>W: append to MEMORY.md R-->>C: reply text end end

Request Flows

TELEGRAM USER MESSAGE

1
User sends message to Telegram bot
2
telegram_channel.py validates user allowlist
3
runner.run("dm:telegram:{user}", text)
4
Claude loop → tools → reply text
5
Reply sent back via Telegram

HEARTBEAT (every N min)

1
APScheduler fires heartbeat_tick()
2
Agent checks HEARTBEAT.md standing goals
3
Takes autonomous actions via tools

X MENTIONS (every 3 min)

1
APScheduler fires mentions_tick()
2
Fetch new mentions via X API v2
3
Claude drafts reply text
4
Auto-post reply to X
